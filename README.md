# AstraAI 🤖

**AstraAI** — интеллектуальный помощник от **Astra Studios**.

## 🧠 Astra 1

Первая модель проекта — **Astra 1**.

Astra 1 предназначена для общения с пользователем, ответов на вопросы и работы с собственной базой знаний.

## 📚 База знаний

На первом этапе AstraAI использует файл `knowledge.json`, содержащий вопросы и ответы.

База знаний будет постепенно расширяться.

## 📱 Технологии

- Android
- Kotlin
- Gradle Kotlin DSL
- Jetpack Compose

## 🚀 Развитие проекта

В будущем AstraAI может получить:

- 💬 более умные ответы;
- 📚 расширенную базу знаний;
- 🖼️ генерацию изображений;
- 🔊 работу с голосом;
- 🧠 новые версии модели Astra.

### Версии

- **Astra 1** — первая версия модели.
- **Astra 2** — будущая улучшенная версия.
- **Astra 3** — будущая версия.
